Building a brand from scratch

Blosm Uniquely Flavored Whipped Cream was not a side project. It was a sole-founded consumer CPG company built from concept to national retail distribution — every label, every pitch, every pricing sheet, every trade show booth, designed and executed without an agency or a marketing team.

The brand launched with a simple premise: whipped cream has been the same for 50 years. Eight flavors — Cinnamon Praline, Blackberry Amaretto, Dark Chocolate Mocha, French Vanilla, Toasted Marshmallow, and more — changed that. All natural. Gluten free. No artificial anything.

What started as an idea ended at 900+ retail locations with a national Kroger account distributed through KEHE, one of the largest natural food distributors in the country.

Identity built to stand on a shelf

Every element of Blosm — the daisy logo, the bee mascot, the “Catch the Buzz” tagline, the flavor naming system — was developed to communicate fun, premium, and natural simultaneously. That is not an easy brief. Most CPG brands pick two.

The point-of-sale card communicated eight flavors, brand positioning, and key product claims (All Natural, No rBST, Gluten Free, No Artificial Colors or Flavors) in a format small enough to live on a refrigerated shelf display. Every word earned its place.

# Sales performance analysis — territory tracking example
# Demonstrates: data loading, aggregation, and insight extraction

import json
from collections import defaultdict
from datetime import datetime

def load_sales_data(filepath):
    """Load and validate sales records from JSON."""
    with open(filepath) as f:
        records = json.load(f)
    return [r for r in records if r.get("revenue") and r.get("territory")]

def territory_summary(records):
    """Aggregate revenue and deal count by territory."""
    summary = defaultdict(lambda: {"revenue": 0, "deals": 0, "avg_deal": 0})

    for record in records:
        t = record["territory"]
        summary[t]["revenue"] += record["revenue"]
        summary[t]["deals"] += 1

    for t in summary:
        d = summary[t]
        d["avg_deal"] = round(d["revenue"] / d["deals"], 2)

    return sorted(summary.items(), key=lambda x: x[1]["revenue"], reverse=True)

def flag_underperformers(summary, threshold=0.8):
    """Flag territories below 80% of average revenue."""
    revenues = [v["revenue"] for _, v in summary]
    avg = sum(revenues) / len(revenues)
    cutoff = avg * threshold

    return [(t, v) for t, v in summary if v["revenue"] < cutoff]

# Usage
data = load_sales_data("q1_sales.json")
results = territory_summary(data)
underperforming = flag_underperformers(results)

print(f"Top territory: {results[0][0]} — ${results[0][1]['revenue']:,.0f}")
print(f"Territories needing attention: {len(underperforming)}")
